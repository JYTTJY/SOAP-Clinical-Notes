# 🏥 Musculoskeletal Physiotherapy Evaluation System

An interactive **R Shiny** clinical documentation and SOAPER matrix reporting system designed for musculoskeletal physiotherapy evaluations.

🔗 **Live Demo:** [greencare-physio.shinyapps.io/SOAP](https://greencare-physio.shinyapps.io/SOAP/)

---

## ✨ Key Features

- **📄 Document Intake**: Upload & preview patient referral letters and imaging reports (MRI/CT/X-Ray).
- **📋 Dynamic SOAPER Note**: Structured S-O-A-P-E-R assessment matrix with safety red-flag checklists.
- **🛠️ Template Manager**: Pre-set treatment protocols and Home Exercise Program (HEP) templates for quick application.
- **🖨️ PDF & Copy Export**: One-click printable A4 evaluation report generation and plain-text clipboard export.
- **🧪 Trial Mode**: Test system workflows safely without data persistence.
